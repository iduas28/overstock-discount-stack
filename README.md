# Overstock discount code: How to Stack a Working Promo With 2% Cashback at Checkout

Most people searching for an Overstock discount code already know what they want: a box on the checkout page that quietly removes 15% before they pay. What they get instead is a coupon page with twenty codes, a cart that rejects all of them, and no explanation of why.

The reason is usually scope, not expiration. Overstock codes are almost always tied to a brand, a category, or a customer status — first-time buyer, Safavieh shopper, patio furniture buyer. Copied off a page that calls it "sitewide," a scoped code fails instantly and looks broken.

That's the first half of the problem. The second half is that even a code that works is only one of two discounts available on the same order, and most shoppers only take one.

## A discount code is a scoped key, not a universal one

The words "Overstock promo code" and "Overstock discount code" get used interchangeably by coupon sites, and that's where the trouble starts. A code like `SAFA15` is a Safavieh discount. `RUGOTHON20` is a rugs promotion. `OVRHL10` was pushed out as a patio-category code. None of them were ever meant to come off a $600 bedroom set.

Overstock's checkout applies a code against the items in your cart, not against your wishlist. If the brand or category doesn't match, the field returns an invalid-code message, which reads like an expired-code message. Two very different problems, one confusing error.

Practical upshot: before you go hunting for the "best" Overstock discount code, figure out what category your item sits in. A 20% rugs code beats a 10% sitewide code only if you're buying a rug.

**Starting the order from somewhere else.** An ad click, an affiliate link from another site, or a browser autocomplete to Overstock.com will usually overwrite the tracking cookie. Start every order from ShopBack.
